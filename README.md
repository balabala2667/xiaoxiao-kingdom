# 小小战大军

一个适配手机、电脑、iPad 的卡通答题战争游戏首版。使用原生 HTML、CSS、JavaScript 和 Canvas，不依赖外部图片、字体、构建工具或 npm 包。

## 启动

需要 Node.js 20.11 或更新版本，在项目目录运行：

```powershell
npm start
```

浏览器访问 http://localhost:4173 。不要直接双击 HTML，浏览器的 ES 模块需要 HTTP 服务。

手机、iPad 与电脑连接同一个 Wi-Fi，在设备浏览器访问 `http://电脑的局域网IP:4173`。电脑需要保持服务器运行，且本机防火墙允许该端口的局域网访问。未部署公网服务。本机存档不在设备间同步。

```powershell
npm test
```

## 已实现玩法

- 年级（一、二）、学期（上下册）、学科（语文、数学）、难度（简单、普通、噩梦）选择。难度只影响题目与答题积分，战斗不读取难度。
- 自动战斗、8 秒准备、答对召唤两名兵，答错不召兵也不扣分；答题后手动进入下一题，战斗始终进行。
- 国王 5 条命，突破后扣命，受损一方补兵；3 秒掉命保护。归零判胜负。
- 每个课程组合独立关卡进度。第 n 关基础题量为 9+n，超出后继续追加，可提前取胜。
- 每 3 关出现 Boss。每累计击败两只 Boss 奖励一颗充能豆，可跨关存储；星光大招消耗一颗豆，对敌兵造成 110 点伤害。
- 蓝湾电脑国家：结盟、解除、互不攻击、派两名兵协防；解除支援返回，休战 10 秒后可攻击；结盟后蓝湾会持续出兵协助攻击赤岩。
- 国王升级（最多 5 级，增加开局守卫）、近战兵与弓箭兵、治疗和护盾、两只可选宠物、三套城堡配色。
- 答题 10/15/20 积分，通关另奖 50+关卡×5 分。累计积分与兑换余额分开，兑换不影响排名。
- 多个本机玩家独立存档、本机真实累计积分排名、错题收集与复习，错题在本局隔两题重新出现。
- 浏览器中文朗读（依赖设备语音能力）；主动暂停及页面切后台自动暂停。
- 电脑左右布局、平板自适应、手机上下布局，手机战斗期间固定战场，便于同时看题。

## 存档边界

数据位于当前浏览器 `localStorage` 的 `little-kingdom-v1` 键。积分、装备、豆、错题、通关进度实时保存；战场里的小兵和当前战斗不存档，刷新需要重新开始本关。隐私模式、清除网站数据或换浏览器会影响进度保留。没有账号服务和真人联网功能。

## 题库现状

语文 72 道原创题，每个年级/学期/难度有 6 道，题组用完会循环；数学根据知识点动态生成，覆盖数的认识、加减、乘除、人民币和应用题。共 24 种课程难度组合，可无限续题。

**这是人教版方向的基础练习首版，不是已完成逐单元审核的官方同步题库。** 所有题目原创，没有复制教材课文。数学尚未覆盖所有几何、时间和统计知识点；语文题量需要扩充。面向正式教学使用前，应由教师对照学校实际教材版次校核知识点、学期分布和难度。教材近年来修订，不能只凭“人教版”认定内容完全一致。

参考入口：
- [人民教育出版社教材目录](https://www.pep.com.cn/products/jc/)
- [人教社关于统编语文教材修订的说明](https://www.pep.com.cn/bks/xxyw/jzjd/202507/W020250716532280620290.pdf)

## 结构

| 文件 | 用途 |
| --- | --- |
| `index.html` / `style.css` | 页面和响应式布局 |
| `app.js` | UI、存档、答题、商店、排名和错题 |
| `core.js` | 独立战斗引擎、联盟、奖励与购买规则 |
| `questions.js` | 原创语文题、动态数学题、错题重现队列 |
| `renderer.js` | Canvas 地图、城堡、军队、技能效果 |
| `server.mjs` | 无依赖静态服务器 |
| `tests/game.test.mjs` | 战斗、题库、奖励、成长等自动测试 |
